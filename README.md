# CyberShield-FIM 

A lightweight File Integrity Monitoring (FIM) tool built in Python to track and detect unauthorized changes in critical files using SHA-256 cryptographic hashing.

##  Features
- Calculates secure SHA-256 file hashes.
- Establishes a secure baseline of file states.
- Instantly alerts users if any file tampering or unauthorized modification occurs.

##  Tech Stack
- **Language:** Python
- **Libraries:** `hashlib`, `os`
